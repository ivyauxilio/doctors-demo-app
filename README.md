# Doctor's Clinic Information System (DCIS)

A specialized software solution designed to streamline and manage the day-to-day operations of a medical clinic.


## Overview

It's built on:

- Next.js 15.x
- React 19
- TypeScript
- Tailwind CSS V4

## Installation

### Prerequisites
To get started, ensure you have the following prerequisites installed and set up:

- Node.js 18.x or later (recommended to use Node.js 20.x or later)

### Cloning the Repository
Clone the repository using the following command:

```bash

```

> Windows Users: place the repository near the root of your drive if you face issues while cloning.

1. Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```
    > Use `--legacy-peer-deps` flag if you face peer-dependency error during installation.

2. Start the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    ```
